# ОСНОВА — будівельні послуги

Самодостатній адаптивний лендинг українською мовою на HTML, CSS та JavaScript. Без пакетів, збірки, зовнішніх шрифтів або трекерів. Фото будинку та інтер’єру завантажуються з images.unsplash.com і потребують інтернету. Вбудовані SVG залишені як резерв, якщо фото не завантажиться.

## Перегляд

Завантажте папку `construction-ua` та відкрийте `index.html` у браузері. Для публікації завантажте цей файл на статичний хостинг. Папка незалежна від наявного сайту в корені репозиторію.

## Що є

- Перший екран з архітектурною ілюстрацією.
- Чотири будівельні послуги, принципи роботи, два приклади для натхнення.
- Етапи співпраці, FAQ та форма складання запиту.
- Мобільне меню, клавіатурний фокус, skip-link, підтримка reduced motion.
- Базові title, description, lang=uk та viewport.

## Перед запуском

1. Замініть назву ОСНОВА, тексти, регіон роботи та демонстраційний текст у контактах.
2. Додайте справжні телефон і пошту з посиланнями tel: та mailto:.
3. Замініть стокові фото на власні фотографії та достовірні описи проєктів. Поточний блок позначено «Для натхнення»: він не є портфоліо виконаних робіт.
4. Підтвердьте формулювання про кошторис, графік, договір і гарантію відповідно до реальних умов компанії.
5. За потреби підключіть форму до серверного обробника або CRM. Наразі вона тільки формує та копіює текст, нічого не надсилає і не зберігає. Не додавайте секрети або токени CRM у HTML/JavaScript. Після інтеграції налаштуйте повідомлення про фактичний результат відправлення та повідомлення про обробку даних.
6. Додайте canonical URL та соціальне прев’ю після вибору домену.

## Стилі

Кольори задані CSS-змінними у :root. Адаптація передбачена для ширини до 900 та 600 px. Усі стилі й скрипт містяться в index.html.

## Перевірка

Статично перевірено цілі внутрішніх посилань та наявність одного H1. Перевірка у браузері в цьому середовищі не виконувалася. Перед запуском перевірте вигляд на телефоні й комп’ютері, меню, FAQ, валідацію телефону, формування запиту та копіювання (на HTTPS і при локальному відкритті). При недоступності Clipboard API показується інструкція для ручного копіювання.

## Фото та оновлення текстів

Додано адаптивні img/srcset, пріоритетне завантаження фото першого екрана і відкладене завантаження нижніх фото. Фотографії використовуються тільки як приклади для натхнення; назву компанії та робочі домовленості потрібно адаптувати під реальний бізнес.
